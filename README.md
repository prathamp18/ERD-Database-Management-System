# 📌 ER Diagram & Database Management System

## 📖 Project Overview
This project focuses on designing an **Entity-Relationship Diagram (ERD)** and implementing a **Database Management System** (DBMS) based on the ERD. The system models various academic entities such as **Courses, Departments, Disciplines, Learning Outcomes, and Graduate Attributes**.

## 🏗️ Database Schema
The database is structured into multiple interconnected tables, ensuring **data integrity** and **efficient querying**. Below are the key entities:

- **Course** 📚
- **Department** 🏛️
- **Discipline** 🎓
- **Graduate Attribute (GA)** ✅
- **Graduate Attribute Indicator (GAI)** 📊
- **Course Learning Outcome (CLO)** 🎯
- **Assessment Levels** 📏

## 📂 ER Diagram
The ERD visually represents relationships between different entities, showcasing how courses, disciplines, and graduate attributes interconnect.

## 🛠️ Technologies Used
- **Database**: MySQL / PostgreSQL
- **Tools**: MySQL Workbench, ERD Designer
- **Languages**: SQL

## 🚀 Features
✅ Well-structured relational schema  
✅ Indexing for faster query execution  
✅ Data normalization for reduced redundancy  
✅ Mapping of courses to disciplines and graduate attributes  
✅ Assessment levels to evaluate student learning outcomes
